This is a HTML app that runs on any browser except on anything on IOS.

This is a local app that stores all your data localy, you only need the browser to run the thing, but it works without internet if you want it 

To start, download and open the app in your favourite browser (on IOS you will need HTML reader)

Now, you can create groups, add cards and do whatever you want!

To add an image (or 2) to your card, you need to either have it downloaded in any file type (works offline), or add a link to the image (works only while online)

The app stores all images for offline use in itself, so it might take up a bit more space (the app auto-compressess the files). If you want it to be small, use the link image option

To save any changes, you have to click the save file button, this creates a new file with date and time of download, so you cant mistake old version for a new one
