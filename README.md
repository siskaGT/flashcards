# About the App

This is a browser-based HTML app that works on most modern browsers, with some limitations on iOS.

### How it works

The app runs entirely locally in your browser and stores all your data on your device. No installation or internet connection is required. You only need a web browser to run it, and it can work completely offline.

### Getting Started

1. Download the app.
2. Open the HTML file in your favourite browser.
3. Start creating groups, adding cards, and exploring the available features!

**Note for iOS users:** You will need an HTML reader app to open and run the file.

### Adding Images

You can add up to **two images per card** using either of these methods:

- **Local image:** Select an image stored on your device. It will be saved within the app and remain available offline.
- **Online image:** Paste a direct link to an image hosted on the internet. This option requires an internet connection to display the image.

### Storage and Image Compression

All locally uploaded images are stored directly within the app, allowing you to use them even when offline.

To reduce storage requirements, the app automatically compresses uploaded images. However, adding multiple images will increase the overall file size.

If you want to keep the app as small as possible, use online image links instead.

### Saving Your Data

**Important: Your changes are not saved automatically!**

Whenever you want to save your progress, click the **Save File** button.

This creates a new version of the app containing your latest changes. Each saved file includes the date and time in its filename, making it easy to distinguish newer versions from older ones.
